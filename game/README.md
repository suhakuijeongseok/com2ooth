# 타이밍 배팅 게임

가장 간단한 방법은 프로젝트 루트의 `run_game.cmd`를 더블클릭하는 것입니다. `게임실행.cmd`도 동일하게 동작합니다.

PowerShell에서는 다음 명령으로도 실행할 수 있습니다.

```powershell
.\run_game.ps1
```

브라우저에서 `http://localhost:8765/game/`이 열립니다. 투수를 고른 뒤 `SPACE` 또는 화면 버튼을 한 번 눌러 투구를 시작하고, 공이 타석에 도착할 때 다시 눌러 스윙하세요. 서버 종료는 PowerShell 창에서 `Ctrl+C`입니다.

- 선수 목록: `output/pitchers.json`
- 구종 선택: 각 투수의 `ratio`를 가중치로 사용
- 공의 도착 속도: `velocity_kmh` 반영
- 구종별 궤적: 포심, 투심, 커터, 슬라이더, 커브, 체인지업, 포크볼 등 구분
- 판정: 도착 직전 타이밍 오차에 따라 PERFECT, 안타, 헛스윙 판정
- 시점: 타석의 눈높이에서 보는 1인칭 카메라, 투수 와인드업과 공의 원근/회전/구종별 무브먼트 적용
